Engineering decisions

Separate models for separate evidence

Live scoring learns from 120 real VM observations. Replay scoring uses a separate synthetic baseline. Replays never enter the live training data.

Operational controls

Token-protected API, input validation, incident acknowledgment, audit records, bounded local retention, and baseline version metadata.

Production path

Longer vetted baselines, signed telemetry agents, tenant isolation, TLS + SSO/RBAC, alert integrations, drift review, and availability testing.
